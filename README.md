# Gigabom Internet Fibra — Site

Site institucional da Gigabom Provedor de Internet (Extremoz, Ceará-Mirim e Maxaranguape - RN).

HTML/CSS/JS estático, sem dependências de build. Para rodar localmente:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Deploy (GitHub Pages)

Este repositório está configurado para publicar via GitHub Pages a partir da branch `main`, pasta raiz.
